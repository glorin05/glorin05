## ◈ Featured Projects

<details>
<summary><b>⬡ Atobits — AI Habit Tracker with Voice Coach</b></summary>

<br />

> A Flutter-based cross-platform habit tracking app powered by an AI voice coach named Atom. Built on a Cloudflare Workers backend proxy to keep API keys off-device while delivering real-time coaching feedback.

<div align="center">

| Attribute | Detail |
|---|---|
| **Stack** | Flutter · Dart · Cloudflare Workers · Groq API · Firebase |
| **Scale** | Cross-platform (Android + iOS) · Production-deployed |
| **Performance** | Sub-200ms voice response via Cloudflare edge proxy |
| **Security** | API key abstraction via serverless proxy · No client-side secrets |
| **Impact** | Published app · Personal productivity · AI coach UX pattern |
| **Repository** | [github.com/glorin05](https://github.com/glorin05) |

</div>

Atobits solves the habit-tracking cold-start problem through conversational AI. The voice coach Atom interprets free-form user input, matches habits via fuzzy logic, and responds with structured coaching feedback. The Cloudflare Workers layer acts as a secure middleware between the Flutter client and Groq's inference API — eliminating the common anti-pattern of bundling API keys in mobile binaries.

<br />

</details>

<details>
<summary><b>⬡ Self-Healing RAG — Agentic Retrieval Pipeline</b></summary>

<br />

> A LangGraph-based Retrieval-Augmented Generation system with self-healing capabilities — automatically detects low-confidence retrievals and re-routes queries through corrective agents before generating responses.

<div align="center">

| Attribute | Detail |
|---|---|
| **Stack** | LangGraph · Groq API · ChromaDB · Python |
| **Scale** | Research-grade pipeline · Modular agent architecture |
| **Performance** | Corrective retrieval loop reduces hallucination rate significantly |
| **Security** | Local vector store · No external data leakage |
| **Impact** | Demonstrates production-pattern RAG beyond naive retrieval |
| **Repository** | [github.com/glorin05](https://github.com/glorin05) |

</div>

Most RAG implementations fail silently — returning low-relevance chunks and generating hallucinated answers with false confidence. This system wraps the retrieval step in a LangGraph state machine that grades chunk relevance, triggers a corrective retrieval agent on failure, and only proceeds to generation once a confidence threshold is met. A practical implementation of the self-RAG research pattern.

<br />

</details>
